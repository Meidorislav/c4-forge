# Architecture Decision Records

Significant technical decisions are recorded here, one file per decision, numbered in order.

Each ADR has a status:

- **Proposed** — under discussion or waiting for validation (e.g. a spike).
- **Accepted** — agreed and in effect.
- **Superseded by ADR-XXXX** — replaced by a later decision; kept for history.

An accepted ADR is not edited in substance. If a decision changes, a new ADR supersedes it.
